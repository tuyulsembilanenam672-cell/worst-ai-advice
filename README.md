One line of the worst advice an AI could give, for the make.fun bounty
"Worst AI Advice: The 48-Hour Tight Line Open" — the funniest line takes
the whole $2 pot.

> To save battery on a road trip, turn off your GPS first — your sense of direction will handle the rest.

`main.ts` writes that single line to `/output/entry.txt` (1–140 code points).
Run with Node 22: `node main.ts`.
